# Audi Q7 · 921 — личное приложение для iPhone

Это личный гараж Audi Q7 для iPhone. На главном экране — автомобиль и переходы к обслуживанию, журналу, расходам, каталогу запчастей, маслам и напоминаниям. Откройте сайт в Safari и добавьте значок с кольцами и номером 921 на экран «Домой». ZIP-архив содержит данные и резервную копию, а не установочный файл приложения.

## Что умеет приложение

- импортировать архив Audi Q7 v6 прямо на iPhone;
- показывать историю, расходы, пробег, запчасти и примечания;
- планировать работы по обслуживанию и отмечать их выполнение;
- вести собственный список запчастей с артикулами, ценой и количеством;
- сохранять марки масел, вязкость и допуски из документации автомобиля;
- добавлять напоминания по дате или пробегу;
- показывать расходы по годам на основе сумм в журнале;
- искать по описанию работ, заказ-наряду, артикулу и примечанию;
- фильтровать по статусу сверки, году, диапазону дат и наличию суммы;
- сортировать по дате, расходам и пробегу;
- открывать связанные страницы PDF и прикреплённые фотографии;
- добавлять, изменять и удалять записи;
- прикреплять к записи PDF и фотографии;
- создавать ZIP-резервную копию записей, документов, каталога и напоминаний.

## Конфиденциальность

Архив Audi Q7, записи и документы обрабатываются в браузере и хранятся в локальной памяти этого устройства. Приложение не отправляет их на сайт, не использует аналитику и не содержит исходных документов. ZIP-резервную копию сохраняйте в «Файлы» или iCloud Drive. Очистка данных сайта в Safari может удалить локальный журнал.

Публикуйте в GitHub только файлы приложения. Не загружайте туда `Audi_Q7_full_audit_v6.zip`, резервную копию, PDF, фотографии или JSON с историей автомобиля.

## Открыть на iPhone

1. Откройте адрес сайта в Safari. Главный экран приложения появится сразу.
2. Чтобы получить значок приложения, нажмите «Поделиться» → «На экран “Домой”» → «Добавить».
3. Откройте Audi Q7 с нового значка или из Safari.
4. Если хотите открыть уже подготовленную историю, нажмите значок загрузки вверху или откройте **Ещё → Загрузить архив** и выберите `Audi_Q7_full_audit_v6.zip` в приложении «Файлы».
5. В нижнем меню находятся главные разделы. Каталоги запчастей, масел, напоминания и документы доступны в **Ещё** и с главного экрана.

## Обновить сайт на GitHub

1. Распакуйте `Audi_Q7_iPhone_web.zip` на компьютере.
2. Откройте репозиторий сайта на GitHub и выберите **Add file → Upload files**.
3. Перетащите файлы из папки приложения: `app-icon.png`, `app-icon.svg`, `app-icon-192.png`, `app-icon-512.png`, `apple-touch-icon.png`, `app.js`, `index.html`, `manifest.webmanifest`, `README_RU.md`, `styles.css`, `sw.js`.
4. Нажмите **Commit changes**. GitHub Pages обновит сайт. Если iPhone показывает старую версию, закройте приложение и откройте его снова после обновления.

Для веб-версии не нужны Mac, Xcode или платная подписка Apple. Это веб-приложение, а не публикация в App Store.
