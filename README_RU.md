# Журнал ТО — веб-приложение для iPhone

Это небольшое приложение, которое открывается в Safari и может быть добавлено на экран «Домой». Оно умеет читать архив Audi Q7 v6 прямо на телефоне: показывает 40 записей, ищет по работам и деталям, фильтрует по году и открывает связанные страницы PDF.

## Личные данные

В этом комплекте находится только пустая оболочка приложения. Истории Audi, VIN, госномера, фотографии и PDF внутри нет. Архив v6 выбирается отдельно в Safari и обрабатывается на iPhone. Архив, записи и нужные PDF сохраняются в локальном хранилище браузера; приложение не отправляет выбранный файл на сайт и не использует аналитику.

Храните оригинальный `Audi_Q7_full_audit_v6.zip` отдельно как резервную копию. При очистке данных Safari локальную копию приложения может понадобиться импортировать снова.

## Как открыть на iPhone

1. На компьютере распакуйте `Audi_Q7_iPhone_web.zip`.
2. Создайте на GitHub репозиторий для сайта и загрузите туда содержимое этой папки. В репозиторий не добавляйте архив Audi.
3. В репозитории откройте **Settings → Pages** и включите публикацию из ветки `main`, папки `/(root)`. После публикации GitHub покажет HTTPS-адрес сайта.
4. Откройте этот адрес в Safari на iPhone.
5. Нажмите «Поделиться» → «На экран Домой» и запустите приложение с нового значка.
6. Нажмите «Выбрать архив» и выберите `Audi_Q7_full_audit_v6.zip` из приложения «Файлы».

После первого открытия оболочка будет работать без сети. Импортируйте архив уже в том варианте, которым будете пользоваться дальше — в Safari или в отдельном приложении с экрана «Домой».

## Разместить файлы

Архив `Audi_Q7_iPhone_web.zip` можно распаковать и загрузить как статический сайт. В корне сайта должны лежать `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js` и `app-icon.png`. Сборка и платный аккаунт Apple для веб-версии не требуются. Для размещения публично доступен только код оболочки; личный архив Audi храните отдельно.
